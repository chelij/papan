# Papan ecosystem upkeep

- Before changing the phone receiver, saved/exported/encrypted formats, companion integrations, or releases, read [docs/ecosystem.md](docs/ecosystem.md) and follow its tracking and upkeep rules.
- Cross-component work is complete when affected contract/compatibility entries and the coordinating issue reflect the change, checks, and remaining limits. Published releases also update the inventory.
- Desktop owns collection formats and the receiver protocol. Android code lives in `chelij/papan-android`; ComfyUI runtime, tests, and releases live in `chelij/comfyui-papan`. The embedded extension path is a migration pointer.
- Consult [docs/development.md](docs/development.md) for affected checks and [docs/verification.md](docs/verification.md) for evidence that can be reused.
