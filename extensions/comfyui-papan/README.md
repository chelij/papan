# Papan for ComfyUI has moved

The canonical extension source, tests, installation guide, and releases live in **[chelij/comfyui-papan](https://github.com/chelij/comfyui-papan)**.

- [Install or update](https://github.com/chelij/comfyui-papan#install)
- [Download the standalone release](https://github.com/chelij/comfyui-papan/releases/latest)
- [Development and checks](https://github.com/chelij/comfyui-papan#development-and-releases)
- [Report an extension issue](https://github.com/chelij/comfyui-papan/issues)
- [Papan ecosystem and compatibility](../../docs/ecosystem.md)

This directory is a migration pointer and contains no installable extension. Desktop Papan no longer builds or publishes a ComfyUI ZIP. Use the standalone repository for all extension changes.

To replace an older embedded-copy installation, back up its extension folder, install the standalone extension in the active ComfyUI installation's `custom_nodes/comfyui-papan`, and refresh/restart as the installation guide describes. Keep only one active extension copy. Preserve ComfyUI's existing input files and saved workflows.
